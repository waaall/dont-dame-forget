# 声音设置实现与 Android 部署测试（2026-10-23）

日期按北京时间记录。使用本项目专用 Android 35 x86_64 模拟器 `DontForget_API35`（`emulator-5554`）；模拟器自身为 UTC，因此截图与原生日志日期可能显示 10 月 22 日。

## 已实现

- 每条提醒可选择系统闹钟铃声并恢复系统默认，保存音源 URI 与显示名称。
- 独立播放音量 10–100%，使用播放器增益，不改变全局闹钟音量。界面说明系统音量限制，系统为零时显示提示。
- 渐强可关闭或选择 15、30、60、120 秒。推迟后重新渐强，页面切换不重置，复查沿用原配置。
- 试听与正式响铃共用原生播放器；可主动停止，渐强结束 5 秒后自动停止（最短 10 秒），页面退出、后台和实际闹钟开始时停止。
- 音源不可用时依次尝试系统默认闹钟铃声、默认通知铃声、内置提示音；异步准备超时会尝试下一音源。
- 旧计划与旧 occurrence 快照缺少声音字段时使用系统默认、100% 播放音量、渐强关闭。

## 调试与修正

1. **声音卡片的读屏标签合并。** 实际 Android 无障碍树最初将整个卡片读为一个按钮。声音卡片改为分别暴露子控件，音量滑条增加完整语义名称。最终设备树分别出现铃声、音量、渐强和试听等节点。
2. **编辑页保存按钮被系统导航栏部分覆盖。** 设备实际为 edge-to-edge 布局；原底部固定间距不足。编辑器增加系统底部安全间距，并以小屏、双倍字号和模拟底部 inset 做回归检查。最终截图中保存按钮下沿为 2190 px，导航栏从 2274 px 开始，按钮完整可见。
3. **试听与正式播放资源管理。** 主线程统一管理准备、增益、音频焦点和释放；增加异步准备超时兜底，保留已响铃时间以恢复渐强进度，只持有 application context。
4. **安装后的通知授权前置条件。** 专用模拟器原先装有更高测试版本号；测试工具首次重装后权限被重置。改用先安装专用测试 APK 并授权，再执行集成测试，最终四组全部通过。没有在个人手机上运行清理数据测试。
5. **历史 ANR 记录核对。** `dumpsys activity services` 含旧 UID 10149 的 Last ANR 缓存；本次最终安装的 UID 为 10154。已核对当前退出历史，仅为覆盖安装导致的进程退出，最终 release 日志未见本轮崩溃或 ANR。保留原始诊断文件，不把历史缓存当作当前活动服务。

## 验证边界

- 本次是 Android 35 专用模拟器部署验收，没有连接三星 S20 真机；真实扬声器响度、振动、长时待机、省电策略及不同厂商铃声选择器仍需真机确认。
- `mWakefulness=Dozing` 的熄屏测试不等于 Android 深度 Doze 长时验收。
- 原生播放器状态与增益检查证明代码实际执行，不等同于声压测量或真人听感验收。
- 本轮没有重新验收重启解锁前、修改时区等全部旧场景，也没有增加本地音乐导入。
- 当前签名仍为项目既有自用 debug 签名流程；需保留同一签名以覆盖安装。首次使用需设置自己的应急密码。
