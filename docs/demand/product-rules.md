# 第一版产品规则

Flutter 应用，Android 首发，最低 API 26，主要面向三星 S20 等较新手机。个人自用，release APK 安装，参考阅读器分发流程。iOS、账号、云同步不在第一版范围。

## 提醒与推迟

- 场景：起床、待办、习惯、其他；单次或选择每周重复日期。
- 推迟没有次数上限。长按仅推迟，不代表完成。
- 默认推迟时长在设置中配置，每条提醒可覆盖；范围 1–1440 分钟。触发后可选常用时长或自定义时长，随后仍需长按执行。
- 创建时指定解除方式：算题，或扫描预先登记的二维码/条形码。触发后不可临时修改任务。
- 算题三档难度、1–10 题，默认简单、3 题。扫码支持位置备注。
- 默认任务通过即完成本次提醒。每条提醒可开启一次完成后复查，默认间隔 10 分钟。
- 复查沿用原任务，可无限推迟；复查任务通过后结束，不继续追加复查。
- 已推迟的提醒可以提前打开并完成任务；等待复查时不能提前提交任务。

## 应急关闭

先设置全局应急密码。绕过任务必须同时输入正确密码和完整原文：

`我发誓我没忘，让我关上吧`

中英文界面均使用这条原文，关闭记为“跳过”，不继续本次复查，重复计划保留。修改密码需验证当前密码。

## 防止绕过

响铃、已推迟、等待复查的提醒，禁止通过删除计划、关闭开关或修改任务绕过。普通返回操作不会解除任务；音频独立于页面。强制停止、撤权、关机、卸载仍由 Android 系统控制。

## 界面

提醒、记录、设置三个主入口；任务页底部固定长按推迟入口。中英双语即时切换，用户内容不翻译。浅色、深色及跟随系统主题。首次启动没有示例业务数据，快速模板只预填创建表单。
